# Security Policy

## Supported Versions

Only the latest release of NOTES receives active security updates and patches.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within NOTES, please do not open a public issue.

Please report all security vulnerabilities privately:

- **Security Contact**: Email security vulnerabilities to [security@clstre.com](mailto:security@clstre.com).
- **GitHub Security Advisories**: You can also use the "Report a vulnerability" button under the **Security** tab of this repository.

Please include:

- A clear description of the vulnerability and its potential impact.
- Steps or code to reproduce the issue.
- Suggested fixes or mitigations if available.

We acknowledge all vulnerability reports within 48 hours and work to issue patches promptly.
