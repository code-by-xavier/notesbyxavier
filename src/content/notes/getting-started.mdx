Welcome to **Notesby**. In Notesby, every post you publish is called a **note**—just like messages on social platforms, but crafted for calm, high-signal long-form reading.

## Note Categories

Every note belongs to a category defined in its frontmatter:

```yaml
category: 'Essays' # or "Op-Eds", "Field Notes", or any custom category
```

On your homepage, each category displays as an interactive horizontal slider row. Readers can slide through your notes smoothly across both desktop and mobile devices.

## Writing Your Thoughts

Every note in Notesby is written in MDX—combining the clarity of Markdown with the power of web components:

> "Simplicity is prerequisite for reliability." Writing in a calm, focused environment allows ideas to develop with precision.

## Automatic Table of Contents

Notice the **Contents** sidebar on the left. You do not need to build or maintain this menu manually:

1. Whenever you add a section heading using `## Heading Title`, Notesby indexes it automatically.
1. Sub-headings created with `### Sub-heading` nest beneath their parent section.
1. As readers scroll through your note, the sidebar dynamically highlights the active section in real time.

## Customizing Categories

You can customize the categories shown on your homepage inside [`notes.config.ts`](../../notes.config.ts):

```typescript
categories: [
  {
    name: 'Essays',
    description: 'Long-form editorial explorations, architectural thought, and in-depth research.',
  },
  {
    name: 'Op-Eds',
    description: 'Sharp commentary, cultural critique, and focused perspectives.',
  },
  {
    name: 'Field Notes',
    description: 'Short-form dispatches, micro-essays, and raw observations.',
  },
];
```
