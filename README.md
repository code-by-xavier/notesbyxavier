# NoteBy

> An open-source, minimalist static publishing engine built on [Astro](https://astro.build).

Designed for writers, thinkers, and essayists who value calm typography, high-signal reading, and publishing without managing complex databases or servers.

---

## Why NoteBy?

- **Distraction-Free Reading**: High-contrast editorial serif typography with comfortable line-height and optimal reading column width.
- **Automatic Table of Contents**: Dynamic left-hand sidebar that indexes headings and tracks reading progress.
- **Instant Dark and Light Modes**: Fast theme toggle that respects user preference with zero screen flicker.
- **Landscape Card Grid**: Clean, 3-column horizontal card layout on the homepage.
- **Single-File Setup (`notes.config.ts`)**: Customize your name, bio, site title, avatar, and social links in one simple file.
- **Zero-Maintenance Static Output**: Compiles into pure HTML and CSS with sub-second page loads.
- **Future-Ready for Writers**: Built to support future lightweight visual drafting editors.

---

## Quick Start (For Developers)

```bash
# 1. Install dependencies
pnpm install

# 2. Start local writing server (port 4330)
pnpm dev

# 3. Build for production
pnpm build
```
